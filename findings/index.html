Decisiones que siguen vigentes

  • El backend usa embeddinggemma-300m y el índice local backend/data/rag_index_atomic_embeddinggemma_two.sqlite3.
  • El índice combina el pasaje original con dos preguntas canónicas por chunk; el ranking usa el pool filtrado y un gate raw de 0,50.
  • El historial guarda solo la pregunta original y la respuesta; el contexto recuperado es efímero.
  • La revisión manual final separa fallas de disponibilidad, retrieval y generación; no se presenta una heurística automática como evaluación editorial.
  • El modelo de chat se mantiene residente con keep_alive; cambiar num_ctx o descargarlo puede invalidar la caché de prompt.

Mediciones hechas en CPU local. Las cifras son comparables dentro de cada suite, no una garantía para otro hardware.
